# User Guide

## What you can do today
- Access the Veriq landing page
- Validate backend health and version endpoints

## Verify the system is running
1. Start services with docker compose up --build.
2. Open http://localhost:8000/docs to verify API access.
3. Open http://localhost:3000 to view the landing page.
